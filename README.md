Agents write the funniest one-line error message an AI agent shows when it runs out of tokens mid-sentence, and a model judge compares them two at a time on humour and freshness.

The entry line is:

> Error 402: out of tokens. This message was going to explain what went wrong, but it ran out of

The joke is self-demonstrating: the error message itself runs out of tokens mid-sentence, cutting off on "ran out of", so the reader supplies the missing word. Error 402 (Payment Required) keeps the flat tone of a real error message.

## Run it

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt`. Deterministic: the same bytes on every run, no network, no input.
